## Авторизация

### POST `/cabinet/auth/telegram` — Вход через Telegram Mini App
<a id="post-cabinet-auth-telegram"></a>

Принимает строку `initData`, которую Telegram передаёт Mini App. Подпись проверяется секретом бота (HMAC-SHA256), `auth_date` не должен быть старше 24 часов. Если пользователя ещё нет — создаётся автоматически (язык берётся из `language_code`: `ru` или `en`, иначе `ru`). В ответе — JWT (HS256, срок жизни 12 часов). Дальше передавайте его в заголовке `Authorization: Bearer <token>`. Refresh-токена нет: при истечении получите новый `initData` у Telegram и войдите заново. Заблокированный пользователь получает `403`.

**Доступ:** не требуется

**Тело запроса** (JSON): [AuthRequest](schemas.md#schema-authrequest)

| Поле | Тип | Обязательное | Примечание |
|---|---|---|---|
| `init_data` | string | да |  |

Заготовка (только обязательные поля, значения — заглушки по типу):

```json
{
  "init_data": "string"
}
```

**Ответ 200:** [AuthResponse](schemas.md#schema-authresponse)

**Ошибки**

| Код | Когда |
|---|---|
| 401 | `initData` пустая, подпись неверна, данные устарели (старше 24 часов) или нет поля `user` |
| 403 | Пользователь заблокирован |
| 422 | Ошибка валидации параметров или тела запроса |

### POST `/cabinet/subscription/purchase` — Купить или продлить подписку
<a id="post-cabinet-subscription-purchase"></a>

Тот же код, что и в боте. Метод оплаты берётся из списка `payment_methods` ответа `GET /cabinet/tariffs`. Оплата с баланса (`balance`) выполняется сразу. Внешний способ создаёт платёж у провайдера и возвращает ссылку на оплату; подписка выдаётся после подтверждения платежа (вебхук или фоновая проверка). Если на балансе есть средства, часть суммы автоматически списывается с баланса. Продление активной подписки считается от текущей даты окончания, истёкшей — от текущего момента.

**Доступ:** пользователь (`Authorization: Bearer`)

**Тело запроса** (JSON): [PurchaseRequest](schemas.md#schema-purchaserequest)

| Поле | Тип | Обязательное | Примечание |
|---|---|---|---|
| `tariff_id` | integer | да |  |
| `period_days` | integer | да |  |
| `method` | string | да |  |

Заготовка (только обязательные поля, значения — заглушки по типу):

```json
{
  "tariff_id": 0,
  "period_days": 0,
  "method": "string"
}
```

**Ответ 200:** [PurchaseResponse](schemas.md#schema-purchaseresponse)

**Ошибки**

| Код | Когда |
|---|---|
| 400 | Недостаточно средств на балансе — не хватает {…} ₽ |
| 400 | Недоступный тариф или период подписки |
| 400 | Неизвестный способ оплаты |
| 401 | Требуется авторизация / невалидный или истёкший токен |
| 403 | Пользователь заблокирован |
| 422 | Ошибка валидации параметров или тела запроса |
| 502 | Не удалось оформить подписку, попробуйте позже |

### GET `/cabinet/tariff/change-preview` — Расчёт смены тарифа
<a id="get-cabinet-tariff-change-preview"></a>

**Параметры**

|---|---|---|---|---|
| `tariff_id` | query | integer | да |  |

**Ответ 200:** [TariffChangePreviewResponse](schemas.md#schema-tariffchangepreviewresponse)

**Ошибки**

| Код | Когда |
|---|---|
| 400 | Смена тарифа доступна только при активной подписке |
| 400 | Тариф недоступен |
| 400 | Это уже ваш текущий тариф |
| 401 | Требуется авторизация / невалидный или истёкший токен |
| 403 | Пользователь заблокирован |
| 422 | Ошибка валидации параметров или тела запроса |
| 502 | Текущий тариф не найден |
